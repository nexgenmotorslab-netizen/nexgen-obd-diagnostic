# NEXGEN OBD - OBD-II Diagnostic Tool

An open-source Python-based OBD-II diagnostic scanner with a Flask web dashboard for real-time vehicle monitoring and fault code analysis.

## 🚗 What it Does
NEXGEN OBD connects to any vehicle via an OBD-II adapter and reads live engine data. It decodes Diagnostic Trouble Codes (DTCs) and visualizes key metrics for drivers, mechanics, and automotive software applications.

## ✨ Key Features
- **Live Data Monitoring**: RPM, Vehicle Speed, Coolant Temperature, Engine Load
- **Fault Code Reader**: Read, decode, and clear DTCs from the car's ECU
- **Web Dashboard**: Real-time charts and data visualization using Flask
- **Diagnostic Analyzer**: Human-readable explanations for error codes
- **Hardware + Software**: Works with any ELM327 OBD-II Bluetooth/USB adapter

## 🛠️ Tech Stack
- **Language**: Python 3
- **Libraries**: `python-OBD`, `Flask`, `pandas`, `matplotlib`
- **Hardware**: OBD-II to USB/Bluetooth adapter
- **Other**: REST APIs, Data Processing, Embedded Systems
